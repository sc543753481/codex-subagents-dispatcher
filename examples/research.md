# Example: Multi-Source Research

User request:

```text
Use subagent-dispatcher to compare five AI note-taking tools for a small product team. Prioritize workflow fit, pricing, integrations, and risks.
```

Expected dispatch:

- Explorer 1: Tool A evidence.
- Explorer 2: Tool B evidence.
- Explorer 3: Tool C evidence.
- Explorer 4: Tool D evidence.
- Explorer 5: Tool E evidence.

Alternative dispatch for a long vendor list:

- Explorer 1: Pricing and limits.
- Explorer 2: Integrations.
- Explorer 3: Team workflow and collaboration.
- Explorer 4: Reliability, lock-in, and risks.
- Explorer 5: Official docs and primary sources.

Expected synthesis:

- Rank the tools for the stated team.
- Call out weak or missing evidence.
- Separate facts from judgment.
- Recommend one default choice and one fallback.
