# Launch Checklist

Use this checklist when preparing a public update for `subagent-dispatcher`.

## GitHub Repository

- Keep the repository description focused on the outcome:
  `Codex plugin that helps Codex split parallelizable work into focused subagents and synthesize results safely.`
- Use topics that match likely discovery paths:
  `codex`, `openai-codex`, `subagents`, `multi-agent`, `codex-plugin`, `developer-tools`, `ai-coding`, `agent-workflows`, `productivity`, `automation`.
- Publish a release for stable installs.
- Keep the repository check badge green.

## README

- Lead with the problem and value before installation details.
- Keep the one-line install path visible near the top.
- Include one concrete prompt that demonstrates the expected behavior.
- Link to examples for research, debugging, and coding use cases.
- Keep the limitations explicit so the plugin does not overpromise automatic spawning.

## Promotion

- Share a short demo prompt plus the repository link.
- Target Codex users, agent workflow builders, and developer-tool communities.
- Ask for one concrete action at a time: try the install, run the quick test, or report where dispatch rules feel unclear.
- Reuse user questions as README improvements, examples, or release notes.
